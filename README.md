# Secure Shop - Digital Asset Store

Secure digital shop with Threema/Telegram integration for encrypted notifications.

## Features
- Stripe payment processing
- Digital downloads via secure S3 links
- Encrypted notifications via Threema and Telegram
- SendGrid email notifications
- Security middleware (helmet, rate limiting)

## Installation
npm install

## Configuration
cp .env.example .env

## Running
npm run dev
npm start
